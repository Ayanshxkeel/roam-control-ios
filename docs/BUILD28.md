# Build 28: text map tabs

Regular map and Community map now use a compact text-tab style inspired by Following/For You navigation: no surrounding pills or map icons, a brighter bold active label, dimmer inactive label, and a short sliding underline. Text shadows maintain contrast over the underlying map. Reduce Motion disables the underline animation. Accessibility retains button and selected-state announcements.

Tab placement, Community default/consent, map functions and sharing behavior are unchanged. Release compilation and whitespace checks are required; final visual contrast and animation comfort still need iPhone testing.
